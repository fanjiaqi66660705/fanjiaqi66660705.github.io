01六步抓取链路

每一步都有对应代码模块，脚本底部按顺序串成 main()，一条命令跑完全程。

环节做什么关键实现
① 目标定位确定公开数据源与采集字段只选公开可访问页面（政府公开数据、统计公报、公开列表页）；字段双轨：展示字段（标题/日期/来源）+ 追溯字段（原文 URL）
② 请求抓取模拟浏览器发请求拿 HTMLrequests + UA 伪装 + 指数退避重试 ×3 + 限速 ≥1s/次
③ 解析提取从 HTML 抽结构化字段BeautifulSoup 按选择器提取，校验失败记为缺失，不硬编码脏值
④ 清洗去重治理成可分析数据pandas：URL 主键去重 → 日期统一 → 标签清理 → 缺失值填充
⑤ 结构化落盘输出双格式文件CSV（utf-8-sig）Excel 打开不乱码 + JSON 程序可读
⑥ 接入分析数据直接进分析工作台CSV 拖入分析页即可跑频数/交叉/卡方/图表，抓取→分析闭环

02核心代码（可直接复用）

Python 3.9+requestsbeautifulsoup4lxmlpandas
# scraper.py —— 公开数据采集流水线（示例目标：公开列表页）
import time, random
import requests
from bs4 import BeautifulSoup
import pandas as pd

HEADERS = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"}

def fetch(url, retries=3):
    """请求抓取：UA 伪装 + 指数退避重试 + 限速"""
    for i in range(retries):
        try:
            r = requests.get(url, headers=HEADERS, timeout=10)
            r.raise_for_status()
            time.sleep(1 + random.random())          # 限速：≥1s/次
            return r.text
        except requests.RequestException:
            time.sleep(2 ** i)                        # 指数退避 1s→2s→4s
    return None

def parse(html):
    """解析提取：按选择器抽字段，失败记为缺失"""
    soup = BeautifulSoup(html, "lxml")
    items = []
    for node in soup.select(".list-item"):          # 按目标站点改选择器
        items.append({
            "标题": node.select_one(".title").get_text(strip=True) if node.select_one(".title") else None,
            "日期": node.select_one(".date").get_text(strip=True) if node.select_one(".date") else None,
            "来源": node.select_one(".source").get_text(strip=True) if node.select_one(".source") else None,
            "原文URL": node.select_one("a[href]")["href"] if node.select_one("a[href]") else None,
        })
    return items

def clean(df):
    """清洗四步：去重 → 日期统一 → 标签清理 → 缺失值填充"""
    df = df.drop_duplicates(subset=["原文URL"], keep="first")
    df["日期"] = pd.to_datetime(df["日期"], errors="coerce").dt.strftime("%Y-%m-%d")
    df["标题"] = df["标题"].astype(str).str.replace(r"<[^>]+>", "", regex=True)
    return df.fillna("未知")

def main():
    records = []
    for page in range(1, 6):                       # 目标：前 5 页公开列表
        html = fetch("https://example.org/list?page=" + str(page))
        if html:
            records += parse(html)
    df = clean(pd.DataFrame(records))
    df.to_csv("output.csv", index=False, encoding="utf-8-sig")  # Excel 不乱码
    df.to_json("output.json", orient="records", force_ascii=False, indent=2)

if __name__ == "__main__":
    main()
把 ② 的 URL 与 ③ 的选择器换成课题要抓的公开站点，这条流水线即可服务任何调研课题——这正是"简单爬虫工具 + 公开数据抓取"岗位需要的可迁移能力。

04合规边界（写进代码里，不是写在页面上）

  • 只抓公开数据：不登录、不破解、不绕权限，涉个人隐私的字段一律不采集。
  • 控制请求频率：默认限速 ≥1s/次 + 失败指数退避，尊重对方服务器与 robots 约定。
  • 全程留痕：每条记录带原文 URL 与抓取时间戳，满足挑战杯对数据真实性与可复核性的要求。
